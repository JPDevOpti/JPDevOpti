## What I build at LIME

Information systems for the [LIME](https://github.com/UT-LIME-UdeA) lab, each one its own product, sharing a common architecture and deployment pipeline.

| System | What it does |
|---|---|
| **PATHSYS** | Pathology case management: reception, diagnosis, approval and result delivery |
| **DERMOPAT** | Dermatopathology lab workflow, built on the same base as PATHSYS |
| **FOTODERMA** | Electronic health record for dermatology, with scheduling and clinical photography |
| **TELESALUD** | Telehealth platform for remote consultations |
| **Contigo Antioquia** | Public health program dashboard for the department of Antioquia |
| **SYMPHONY** | Data ingestion hub and shared clinical catalogs that feed the other systems |
| **FORMS** | Form builder where each form becomes a database table |
